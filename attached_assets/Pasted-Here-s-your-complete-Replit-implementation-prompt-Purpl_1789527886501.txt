6. Smart Hub Selection & Dynamic Pricing

Distance Calculation:

Extract customer's pickup address from Trip Details form
Use Google Maps Distance Matrix API to calculate:
Distance from pickup address to Austin Hub (3100 Esperanza Crossing, Austin, TX 78758)
Distance from pickup address to Dallas Hub (777 S Central Expy, Richardson, TX 75080)
Determine which hub is geographically closer
Use closer hub's pricing rates

Price Calculation Formula:

Final Price = Car Class Base Price × Hours (rounded UP)

Duration Calculation:
- Get pickup time and dropoff time from Trip Details
- Calculate time difference in hours
- Round UP to next full hour (e.g., 2h 15m → 3h, 3h 1m → 4h)
- Multiply by car's base hourly rate

Example:

Pickup: 5200 N Lamar Blvd, Austin (closer to Austin Hub)
Car: Business SUV ($150/hour)
Time: 2:30 PM to 5:15 PM = 2 hours 45 minutes
Duration rounded up: 3 hours
Final Price = $150 × 3 = $450

Customer Display:

Show ONLY the final price (no breakdown)
Never show: distance calculations, per-mile rates, hourly rates, time fees, car class premiums
Price updates automatically when:
Pickup/dropoff address changes
Date or time changes
Different car is selected

API Implementation:

Use Google Maps Distance Matrix API
Store API key in Replit Secrets (environment variable)
Cache results for same addresses (reduce API calls)
Handle API errors gracefully (fallback to default pricing if API fails)
